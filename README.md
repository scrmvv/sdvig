# СДВИГ v0.7 — городская доска

Статический сайт для GitHub Pages, без API-ключей, сервера и внешних JS-библиотек. Основан на v0.6. Добавлены **физические узлы на красных нитях**: изменение смысла, перенаправление связи и разрыв с сохранением маршрута.

## Что нового в v0.7

1. Нажмите «Соединить эти идеи» и затем **красный узел** на нити около стикера. Появится бумажная записка с управлением связью.
2. Переключите смысл **«В одной прогулке / По очереди / В одном месте»** — содержимое доски и список мест меняются.
3. На компьютере **перетяните узел нити** на свободный стикер. Интерес в составной теме заменится без очистки маршрута. На телефоне нажмите строку с названием темы в блоке узлов и выберите новую тему в списке.
4. **Отвязать тему** — разрывает только выбранную нить. Если остаётся один интерес, он снова станет начальной точкой для новой связки. **Отменить** восстанавливает предыдущее состояние нитей.
5. В новой записке остается управление всем смыслом связки, поэтому старый блок под доской служит альтернативой, а не отдельной механикой.

## Как показать обратную навигацию v0.6

1. Откройте сайт и нажмите **«Или начни с Арт-Квадрата»** либо соберите пару интересов и нажмите **«Исследовать»** у любого результата.
2. На доске выбранное место станет центральной заметкой. Вокруг появятся только интересы, с которыми оно связано.
3. Нажмите, например, **«Культура»** — красная связь выделится, а подборка следующих объектов изменится.
4. Выберите **«Открыть связи»** у одного из новых мест. Оно станет новым центром, и доска перестроится заново.
5. **«Предыдущее место»** вернёт к предыдущему узлу, сохраняя выбранную ветку; **«К своим интересам»** вернёт к исходной доске.
6. Любое исходное или найденное место можно добавить к маршруту. Список маршрута сохраняется при переходах.

## Что осталось из v0.5

Соединение стикеров перетаскиванием или кликами, составные темы, предугадывание интереса, три смысла нити, редакционная подборка объектов Уфы, настройка количества остановок, экспорт TXT, мобильная навигация и адаптация под уменьшенное движение.

## Публикация на GitHub Pages

Скопируйте **содержимое папки** в корень ветки публикации:

- `index.html`
- `styles.css`
- `app.js`
- `assets/cork.webp`
- `README.md` (необязателен для работы сайта)

В архив включён `CNAME` с `sdvig.scrmvv.space`. Не меняйте его, если публикуете на этом же домене. Затем Commit → Push в VS Code. Настройки GitHub Pages и DNS менять не нужно.

## Данные и ограничения

Места берутся из локального демонстрационного каталога в `app.js`. У них есть тематические теги, но **нет географического расчёта близости или времени в пути**, живой информации о режиме работы и ценах. Переход «место → место» означает **сходство по интересам**, а не кратчайший маршрут. Проверяйте реальные адреса и актуальность мест перед поездкой.
