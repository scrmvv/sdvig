# СДВИГ 0.3 — прототип для SiteHack

Экспериментальная композиционная навигация: пользователь не ищет готовые страницы, а создаёт собственный раздел из пересечения тем. Новый раздел остаётся частью навигационного пространства; в него можно добавлять третью и четвёртую тему.

## Как проверить

1. Откройте `index.html` в Chrome, Firefox или Edge.
2. Нажмите «Природа», затем «Кофе», либо воспользуйтесь кнопкой примера. Появится «Кофе с видом».
3. Добавьте третью тему (например, «Архитектура»): созданный раздел и рекомендации перестроятся.
4. Измените время и ограничения; добавьте две остановки; сохраните TXT.
5. Нажмите на уже выбранную тему, чтобы убрать её из структуры; используйте «Разъединить всё» для возврата.

Вариант без перетаскивания: последовательные нажатия на темы; клавиатура — Tab, Enter или Space.

## Данные

Все 26 мест, их характеристики, цены и длительности придуманы для демонстрации. Реальные маршруты, расстояния и карта не вычисляются. Если у комбинации нет точек с двумя совпадающими темами, интерфейс может показать точки, соответствующие одной из выбранных тем, с прозрачным счётчиком совпадений.

## Технически

Чистые HTML/CSS/JavaScript, без сборки, API и сторонних зависимостей. Рекомендуемые ширины для проверки: 360, 390, 768, 1440 px. Пользовательские ограничения учитываются в демонстрационной подборке, а суммарное время условное.
